# letras

"Letras" game of "Cifras y Letras".

## Interaction example
~~~
$ letras.py

"cache.json" does not exist.


Loading "words.txt" into memory...
Generating JSON cache file "cache.json" to speed up the next executions...

Press Control+C to exit.
Letters (ENTER for randomly generation): 

URUNAUNRS
Press ENTER to show the results...


Results (6 letters):
RUNRÚN
USURAR

Letters (ENTER for randomly generation): iperesacn


Results (9 letters):
PRESENCIA

Letters (ENTER for randomly generation): ^C
Exiting...
$ 
~~~
